# Garrido Studio website

A static product website following the presentation structure of the Aether Matrix site, with Garrido Studio's approved pearl, coral, rose and violet identity. No frontend dependencies, analytics, accounts or backend.

```sh
cd web
pnpm dev
pnpm check
```

Serve `public/` on a static host. Product images must be actual application captures; the official logo remains unchanged. The audio sample is an engine render of the included Primer pulso example. Playback is explicit and pauses when the page is hidden. The CSP blocks external runtime requests; download links navigate to the public GitHub release.

Workflow tabs support pointer and keyboard input. The page respects reduced motion and includes visible focus, native audio controls, responsive layouts and semantic FAQ disclosures. Compatibility, license and distribution boundaries are stated next to the downloads and in the FAQ.
