# Garrido Studio 1.1.0

By **Pelayo Garrido Martínez**.

A revised Garrido Studio workspace: official branding at the left of the header, grouped transport, named editor views, native window controls and a simpler three-tab library. The wider step sequencer uses shared proportional drawing and hit-test geometry, with a regression covering its first and last steps and undo.

The approved logo, moodboard, initial dark theme and explicit light preference are retained. Audio formats, project data and the documented first-party plugin scope are unchanged. The earlier release and development history remain available.

The product website includes real application imagery, an actual engine-rendered example and downloads for macOS arm64, Windows x64 and Linux x64. See CONTRIBUTING.md for current FLP, plugin, recording and export boundaries. Real audio-device, clean-machine and long-session acceptance remain separate from automated native checks.

## Packages

- macOS 13+, Apple Silicon arm64; ad-hoc signed, not notarized.
- Windows x64; publisher signing remains pending.
- Linux x86_64, glibc 2.39 and ALSA with a graphical desktop.

Extract the complete folder and keep its resources together. SHA256SUMS.txt identifies the release assets. The release publisher requires all three native builds, editor/core checks, the included-plugin diagnostics, dependency review and archive integrity checks before publication.
