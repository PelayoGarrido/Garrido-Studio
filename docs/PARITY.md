# Acceptance matrix

Reference: Lemon Studio `a6ce2dd443d75abf424a50fb5dd68526f87bed9d`, its public capability descriptions/status and workspace screenshots. Reference behavior itself has not been independently accepted; the reference describes a prealpha.

**V1 scope:** the implemented workstation flows in README.md. Full reference parity remains a development roadmap, with the remaining work tracked below and in CONTRIBUTING.md. Version 1.0.0 does not imply every reference feature, external plugin or driver has been accepted. Native automation checks and physical/user acceptance remain separate.

## Evidence rule

Use [BUILD-EVIDENCE.md](BUILD-EVIDENCE.md) for current commands, counts and measurements. A generated FLP fixture is not an FL Studio acceptance result. The Apple FLAC cross-check is evidence for its particular generated stereo/48 kHz/24-bit fixture, not every possible file. The CLAP smoke test uses only our own code. No microphone or audible playback is opened by these tests.

The implementation is independent; no Lemon engine, GPL binding, repository asset or sample pack is incorporated. Screenshot geometry is recreated with original drawing code and separately licensed upstream Cuprum/Tabler assets. Legal clearance, listening quality and hardware reliability cannot be inferred from local compilation.
